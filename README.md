# Sobrizen

PWA française d’accompagnement à l’arrêt ou à la réduction de l’alcool.

Frontend statique prévu pour Vercel. Backend Supabase pour l’authentification, les profils, le suivi privé, les check-ins, les envies et la communauté.

## Déploiement

Importer ce dépôt dans Vercel comme projet statique. Aucun build n’est nécessaire.

## Sécurité

Le frontend utilise uniquement la clé publishable Supabase. Les données privées sont protégées côté base par les politiques RLS.
